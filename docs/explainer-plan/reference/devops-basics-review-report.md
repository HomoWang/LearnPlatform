## 會讓讀者學錯、已修正的三件事
1. `git branch` 不會切換分支，原腳本的卡片與檢測題在這個前提下答案相反。【主持人親驗＋Opus 實測】
2. 把分支畫成方塊，刪分支時方塊消失，會讓人以為存檔被刪。【Opus 實測：刪除後 commit 仍在】
3. v2 把分支標籤貼在合併點 M 上；實際合併後標籤留在 C。【Opus 實測，Haiku 同時指出】

## 其他主要修正
